Private & offline. Every check runs inside your own web browser. No file, column, or value is uploaded or sent anywhere — you can run this with your network disconnected.

The convention — required sheet, identifier, and columns per assay
  • Every report must contain a sheet named Upload (the tool matches it ignoring case and spaces).
  • The Upload tab must carry one identifier column with the compound batch id (SRB-XXXXXXX-NNN) — never split into separate Compound ID + Batch No columns.
  • Endpoint column names must match exactly (spelling, spacing, units, and the - PgP inhibitor suffixes are all significant).
  • Numeric result columns must contain numbers only. Never write NA, ND, or any other text — leave the cell empty instead. The import rejects a row that has text in a numeric field. A < or > qualifier (e.g. <0.5) is fine.
  • Run Lab and Molecule Name are allowed but ignored. Any other unexpected column is flagged.
